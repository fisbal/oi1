# Security policy / Politique de sécurité

If you find a security problem in Office In 1 (code that could run from a document, a leaked key,
an unsafe update…), please report it privately: **Security tab → Report a vulnerability**
(https://github.com/fisbal/oi1/security/advisories/new). Do not open a public issue.
You get an answer within 7 days; fixes ship to the web app, the Store app and the installers at once.

Si vous trouvez une faille dans Office In 1, signalez-la en privé : **onglet Security → Report a vulnerability**.
N'ouvrez pas de ticket public. Réponse sous 7 jours.

Supported version: the latest release (all installed apps update themselves).

How Office In 1 protects itself: [docs/securite.md](docs/securite.md).
